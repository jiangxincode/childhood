## 快速开始

```bash
# 克隆项目
git clone https://github.com/jiangxincode/childhood.git
cd childhood

# 安装依赖
npm install

# 直接用浏览器打开即可
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

## 运行测试

```bash
# 执行全部测试
npm test

# 监听模式
npm run test:watch
```
