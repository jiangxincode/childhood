📜 游戏规则

🎮 基本规则

  • 9×9棋盘，先手先走
  • 先手在下，后手上
  • 王被将杀则输

🔄 棋子走法

  • 王：任意方向一步
  • 飞车：直线任意距离
  • 角行：斜线任意距离
  • 金将：前后左右及斜前一步
  • 银将：斜方向及正前一步
  • 桂马：前方向前两步斜一步
  • 香车：正前任意距离
  • 步兵：正前一步

⚔️ 特殊规则

  • 升变：进入敌阵可升级
  • 打入：俘获棋子可重新放置
  • 二步禁：同列不能有两个步兵

🏆 胜利条件

  • 将杀对方王
  • 对方无合法走法（和棋）

🤖 人机模式

  • AI使用Alpha-Beta剪枝
